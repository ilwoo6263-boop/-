# ✦ WISH FREQUENCY

소원을 하나 정하고, 그 목적에 맞는 주파수와 몰입 시간을 시작하는 웹앱 MVP.

## 현재 구현

- 감성적인 다크/글로우 UI
- 재회 / 재물 / 사랑 / 행운 / 집중 / 티라노사우르스 주파수 카드
- Web Audio API 기반 브라우저 주파수 재생
- 주파수별 청취 타이머
- 소원 문장 입력 → 키워드 기반 주파수 추천
- 재생 / 일시정지 / 재시작 / 즐겨찾기 UI
- 모바일 반응형

## 실행

별도 빌드 도구 없이 `index.html`을 브라우저에서 열면 됩니다.

GitHub Pages를 활성화하면 정적 웹앱으로 배포할 수 있습니다.

## 다음 개발 단계

1. 소원별 상세 페이지
2. 주파수 콘텐츠 30~50종 확대
3. 실제 오디오 트랙 및 백그라운드 재생
4. 오늘의 소원 / 연속 청취 기록
5. 로그인 및 개인화
6. 광고 + 프리미엄 구독
7. PWA / 모바일 앱 패키징

> 주파수가 실제로 소원을 이루어준다는 과학적 근거는 없습니다. 본 서비스는 명상·몰입을 위한 엔터테인먼트 콘텐츠입니다.
